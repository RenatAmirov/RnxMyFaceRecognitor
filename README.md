# Распознавание лица

Приложение для Windows показывает большую зелёную галочку, когда узнаёт ваше лицо через веб-камеру. Модели включены в проект. После установки зависимостей приложение работает без интернета.

## Запуск

Дважды щёлкните по `run.cmd`. Если переносите проект на другой компьютер, установите Python 3.15 с Tkinter и выполните в PowerShell из папки проекта:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\run.cmd
```

При наличии нескольких камер выберите другую командой `.\run.cmd --camera 1`.

## Использование

1. Останьтесь в кадре одни и нажмите **Записать лицо**.
2. Смотрите в камеру, пока приложение соберёт пять образцов. Можно слегка повернуть голову.
3. После записи посмотрите в камеру. При совпадении появится зелёная галочка. При следующих запусках приложение использует сохранённый профиль.

Кадры обрабатываются в памяти. На диск сохраняется вектор признаков лица по пути `%LOCALAPPDATA%\RnxMyFaceRecognitor\sface-profile.npy`. Для обновления профиля нажмите **Записать заново**, для удаления закройте приложение и удалите этот файл.

## Модели

- [YuNet для поиска лиц](https://github.com/opencv/opencv_zoo/tree/main/models/face_detection_yunet). Лицензия в `models/YuNet-LICENSE.txt`.
- [SFace для сравнения лиц](https://github.com/opencv/opencv_zoo/tree/main/models/face_recognition_sface). Лицензия в `models/SFace-LICENSE.txt`.
